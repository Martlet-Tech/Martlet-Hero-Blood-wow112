# Martlet Hero Blood（wow112）

魔兽世界 **1.12.1**（Interface 11200，水豚服 / Turtle WoW）用的**英雄之血**世界地图标记插件。

在西瘟疫之地、东瘟疫之地的区域地图上标出英雄之血刷新点，并**自动记录每个点上次被采走的时间**，直接在图标下显示还有多久刷新。

> 原版 `bloodOfHeros` 1.2（作者 Demonass，2020）依赖经典旧世 1.13 的 `C_Map` + HereBeDragons-2.0，
> 在 1.12 客户端上必然空白报错。本插件按 1.12 原生 API 重写了显示逻辑，坐标数据另取。

## 功能

- 西瘟疫之地 **2** 点 / 东瘟疫之地 **6** 点，共 **8** 个刷新位置
- **刷新计时**：采到英雄之血时自动记下是哪个点，图标下方实时显示 `2h00` / `45m` 倒计时，到点变绿显示「可刷」
- 钉子用物品 12938【英雄之血】的图标（自带 64×64 TGA 贴图，不依赖客户端内建图标）
- 悬停显示：区域名 + 精确坐标 + 上次采走于多久之前
- 只使用 1.12 原生 API，**不依赖任何库**，与 pfUI / pfQuest / S_WorldMap / ModernMapMarkers 不冲突

## 安装

1. 下载或克隆本仓库
2. 把 `BloodOfHeroesMap` 整个文件夹放进：

   ```
   <游戏目录>\Interface\AddOns\BloodOfHeroesMap\
   ```

3. 确认该目录下能直接看到 `BloodOfHeroesMap.toc`（不能多套一层文件夹）
4. 进游戏，`/reload` 或重启客户端

1.12.1 默认加载所有插件，**不需要**勾选"加载过期插件"（这个版本还没有该功能）。

## 使用

| 操作 | 说明 |
| --- | --- |
| 打开地图（`M`）→ 切到西瘟疫之地 / 东瘟疫之地 | 自动铺图钉 |
| 鼠标悬停图钉 | 显示坐标与上次采集时间 |
| **捡到英雄之血** | **自动记录该点，计时开始，无需任何操作** |
| 左键点图钉 | 手动记为「刚采走」（自动识别失败时用） |
| `/bh` | 开关显示（设置会被记住） |
| `/bh on` / `/bh off` | 显式开关 |
| `/bh mark` | 把脚下最近的刷新点记为刚采走 |
| `/bh clear` | 清空全部计时记录 |
| `/bh 60` | 把刷新周期设为 60 分钟（默认 120，若本服改过刷率可用） |
| `/bh debug` | 屏幕自检面板 + 聊天框输出判定过程 |

计时记录存在 `WTF\Account\<账号>\SavedVariables\BloodOfHeroesMap.lua` 里，跨登录、跨重启都保留。

### 图钉下的倒计时怎么读

| 显示 | 含义 |
| --- | --- |
| `2h00` / `45m`（黄色） | 距上次采走已过的时间对应的剩余冷却 |
| `可刷`（绿色） | 已超过刷新周期，理论上已经刷出来了 |
| 没有文字 | 这个点还没有采集记录，不知道状态 |

注意倒计时只能反映**你自己**看到的采集。别人抢先采走的点，插件无从得知，仍会按上次记录显示——所以看到「可刷」也可能是空的。

### 只有区域地图有钉子

看**东部王国大陆图**时不会显示——1.12 的大陆图没有精确投影，任何插件都无法定位。请切换到具体的区域地图。

## 坐标数据

`coords.lua`，共 **8** 点，取自 1.12 服务端数据库的精确值：

| 区域 | 坐标 |
| --- | --- |
| 西瘟疫之地 | 49.73, 33.28 ・ 52.35, 54.95 |
| 东瘟疫之地 | 33.58, 32.62 ・ 49.11, 35.32 ・ 59.26, 62.27 ・ 64.73, 65.25 ・ 27.28, 64.15 ・ 25.94, 74.64 |

**数据来源**：[`cmangos/classic-db`](https://github.com/cmangos/classic-db) 的 `Full_DB/ClassicDB_1_12_1_z2815.sql.gz`，`gameobject` 表 entry `176213`（Blood of Heroes）。ClassicDB 网站（`?object=176213`）对同一份数据只筛出 8 个确认点，标为 `Eastern Plaguelands (6), Western Plaguelands (2)`，与本表一致；Wowhead 经典服指南也写 "six easy to find spawns"。

> **为什么不用原插件的 140 点**：那张 `gameobject` 表里其实有 **158 条**刷点记录，原插件就是把它们去重搬了过来。实际存在的只有 8 个，其余是冗余数据（实测西瘟疫只有 2 个）。早期版本从 3DM 攻略取的坐标是这 8 个点四舍五入到 0.1 的结果，现已换成数据库原值。

若要补充或修正点位，直接改 `BHM_COORDS`，格式：

```lua
BHM_COORDS = {
  WPL = { {49.73, 33.28}, ... },   -- 西瘟疫之地，x, y 均为 0-100 的地图百分比
  EPL = { {33.58, 32.62}, ... },   -- 东瘟疫之地
}
```

坐标取值是**游戏内百分比**（0-100），不是 0-1，也不是世界坐标。

## 刷新机制

**刷新时间：固定 2 小时，每个点独立计时，无随机浮动。**

这不是传闻，是数据库字段：

| 来源 | 数据 |
| --- | --- |
| `cmangos/classic-db` 的 `gameobject` 表 | entry 176213 共 158 条记录，`spawntimesecsmin` = `spawntimesecsmax` = **7200**，无一例外 |
| ClassicDB 网站（object 176213） | 8 个点每个都标 `Respawn: 2hr` |
| 3DM / 233乐园 攻略 | 2 小时 |
| MMO-Champion 2010 年玩家实测 | "roughly 2 hours" |

> 网上流传的「8 / 12 / 24 小时」出自 Wowpedia，但原文用词是 *rumored*（传闻）；Warmane 论坛那条「8, 12 and 24 hours」也是玩家猜测。这两处都与数据库字段矛盾，不采用。

由此推出几条实用结论：

- **不是全服同时刷新**。每个点从"被采走的那一刻"开始独立倒计时，所以 8 个点的可用时间互相错开。
- **绕圈收益有限**。一圈 15 分钟，一个周期 2 小时，绕 8 圈才等于一个完整周期；而且 8 个点对着全服玩家，抢不到是常态。
- **服务器重启 / 维护后是最佳时机**。Wowpedia 提到 "more likely to be found just as a server comes back online"；早期玩家实测在重启后 20 分钟内收齐 20-30 个。
- **地上的"英雄之魂"是活体雷达**。这个物件是 Chest 类型，拾取会召唤 1-2 只 58-60 精英 `Fallen Hero`（约 9000 血），入场即放 `Incapacitating Shout`，减速 60% 持续 1 分钟。看到某点附近有这种精英游荡，说明刚被人采过，别在那等。
- **用插件的倒计时代替记忆**。周期长、点位分散，靠脑子记必然出错；采到就自动记，一眼看出哪几个点该跑了。

**外观**：一圈石头围起来的小黑血池。经常半埋在斜坡地形里，只露出一角，很容易走过头。

**脱身**：拾取瞬间就会被减速，硬跑跑不掉。可用手段——PVP 徽章或自由行动药水解减速、猎人冰冻陷阱 + 宠物、法师拾取后连点闪现；脱光装备让怪打死再跑尸也常用，但东瘟疫部分点位离墓地很远，慎用。

## 实现要点（1.12 客户端踩坑记录）

这套客户端有几个和教科书不一样的行为，本插件的写法都是按实测结果定下的：

| 现象 | 处理 |
| --- | --- |
| `WorldMapFrame:IsVisible()` 返回 `nil` | 完全不做可见性判断；钉子挂在 `WorldMapButton` 下，地图关闭时自然隐藏 |
| `GetMapInfo()` 会滞后一个区域（换图后仍返回上一张图的名字） | 区域识别改用**序号比对**：启动时从 `GetMapZones(大陆)` 扫出西/东瘟疫之地的序号，之后只比较 `GetCurrentMapZone()` 的数字 |
| `GetMapZones()` 有的实现返回表、有的返回多个值 | 两种都兼容 |
| `SetTexture("Interface\\Icons\\...")` 渲染为全黑 | 自带 TGA 贴图；且**必须写全 `.tga` 扩展名**，否则客户端只补 `.blp` |
| 换区时 `WORLD_MAP_UPDATE` 连发、地图框尺寸未定型 | 事件触发 + 0.3 秒防抖补帧，另挂 `WorldMapFrame_Update` 与 0.25 秒轮询兜底 |
| 1.12 是 **Lua 5.0**，没有 `string.match` / `string.gmatch` | 全部用 `string.find` 配合捕获返回；也没有 `goto`、`#` 一律用 `table.getn` |
| 1.12 的 `OnEvent` 参数是 `(self, event, arg1, ...)` | 监听 `CHAT_MSG_LOOT` 判断 `arg1` 文本，匹配 `12938` / `英雄之血` / `Blood of Heroes` |
| 拾取瞬间被减速 60%，人可能已经走开几步 | 记录时用 `GetPlayerMapPosition` 找**最近**的点，阈值放宽到地图 2.5%，避免记不上 |
