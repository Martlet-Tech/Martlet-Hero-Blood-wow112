# Martlet Hero Blood（wow112）

魔兽世界 **1.12.1**（Interface 11200，水豚服 / Turtle WoW）用的**英雄之血**世界地图标记插件。

在西瘟疫之地、东瘟疫之地的区域地图上标出英雄之血刷新点，鼠标悬停可看精确坐标。

> 原版 `bloodOfHeros` 1.2（作者 Demonass，2020）依赖经典旧世 1.13 的 `C_Map` + HereBeDragons-2.0，
> 在 1.12 客户端上必然空白报错。本插件按 1.12 原生 API 重写了显示逻辑，坐标数据另取。

## 功能

- 西瘟疫之地 **2** 点 / 东瘟疫之地 **6** 点，共 **8** 个刷新位置
- 钉子用物品 12938【英雄之血】的图标（自带 64×64 TGA 贴图，不依赖客户端内建图标）
- 悬停显示：区域名 + 精确坐标（如 `西瘟疫之地  49.7, 33.3`）
- 只使用 1.12 原生 API，**不依赖任何库**，与 pfUI / pfQuest / S_WorldMap / ModernMapMarkers 不冲突

## 安装

1. 下载或克隆本仓库
2. 把 `BloodOfHeroesMap` 整个文件夹放进：

   ```
   <游戏目录>\Interface\AddOns\BloodOfHeroesMap\
   ```

3. 确认该目录下能直接看到 `BloodOfHeroesMap.toc`（不能多套一层文件夹）
4. 进游戏，`/reload` 或重启客户端

1.12.1 默认加载所有插件，**不需要**勾选"加载过期插件"（这个版本还没有该功能）。

## 使用

| 操作 | 说明 |
| --- | --- |
| 打开地图（`M`）→ 切到西瘟疫之地 / 东瘟疫之地 | 自动铺图钉 |
| 鼠标悬停图钉 | 显示区域与坐标 |
| `/bh` | 开关显示（设置会被记住） |
| `/bh on` / `/bh off` | 显式开关 |
| `/bh debug` | 屏幕自检面板 + 聊天框输出判定过程 |

设置保存在 `WTF\Account\<账号>\SavedVariables\BloodOfHeroesMap.lua`。

### 只有区域地图有钉子

看**东部王国大陆图**时不会显示——1.12 的大陆图没有精确投影，任何插件都无法定位。请切换到具体的区域地图。

## 坐标数据

`coords.lua`，共 **8** 点，取自 [3DM 怀旧服英雄之血攻略](https://ol.3dmgame.com/gl/88300.html)：

| 区域 | 坐标 |
| --- | --- |
| 西瘟疫之地 | 49.7, 33.3 ・ 52.4, 55.0 |
| 东瘟疫之地 | 33.6, 32.6 ・ 49.1, 35.3 ・ 59.3, 62.3 ・ 64.7, 65.3 ・ 27.3, 64.2 ・ 25.9, 74.6 |

> **为什么不用原插件的 140 点**：实测表明那 140 个点里混入了大量非刷新点（疑似来自后续版本或密集采样）。
> 上述 8 个点在其中都能找到对应位置，误差均 ≤ 0.2，说明原表是"真点 + 噪音"混在一起，故不再采用。
> 原链坐标有一处笔误 `25.9,，74.6`，已按 `25.9, 74.6` 处理。

刷新时间约 2 小时。若要补充或修正点位，直接改 `BHM_COORDS`，格式：

```lua
BHM_COORDS = {
  WPL = { {49.7, 33.3}, ... },   -- 西瘟疫之地，x, y 均为 0-100 的地图百分比
  EPL = { {33.6, 32.6}, ... },   -- 东瘟疫之地
}
```

坐标取值是**游戏内百分比**（0-100），不是 0-1，也不是世界坐标。

## 刷新机制

1.12 原版的机制如下，综合 Wowpedia、ClassicDB（object `176213`）与 Warmane 论坛的实测讨论。

**点位固定 8 个，不会随机移动。** ClassicDB 的 object 页面直接写着 `Eastern Plaguelands (6), Western Plaguelands (2)`，与 Wowhead 经典服指南（"six easy to find spawns"）一致。

**刷新计时：每个点独立，分 8 / 12 / 24 小时三档。**

> 依据：Wowpedia 称这些点位 "respawn timers ... anywhere from 8 to 24 hours"；Warmane 论坛讨论 1.12 数据的帖子给出更具体的分档 "8, 12 and 24 hours"。
> 这是社区数据，不是官方文档，且各服可能自行调整。中文攻略站常见的"2 小时"说法来自别的版本，与 1.12 原版不符。

由此推出几条实用结论：

- **不是全服同时刷新**。每个点从"被采走那一刻"开始独立倒计时，8 个点的可用时间互不同步。
- **绕圈巡逻效率极低**。一圈 15 分钟，一个周期 8 小时起，绕 30 圈才等于一个完整周期。资源少是机制问题，不是路线问题。
- **服务器重启 / 维护后是最佳时机**。Wowpedia 明确提到 "more likely to be found just as a server comes back online"；早期玩家实测在重启后 20 分钟内收齐 20-30 个。
- **地上的"英雄之魂"是活体雷达**。这个物件是 Chest 类型，拾取会召唤 1-2 只 58-60 精英 `Fallen Hero`（约 9000 血），入场即放 `Incapacitating Shout`，减速 60% 持续 1 分钟。看到某点附近有这种精英游荡，说明刚被人采过，别在那等。

**外观**：一圈石头围起来的小黑血池。经常半埋在斜坡地形里，只露出一角，很容易走过头。

**脱身**：拾取瞬间就会被减速，硬跑跑不掉。可用手段——PVP 徽章或自由行动药水解减速、猎人冰冻陷阱 + 宠物、法师拾取后连点闪现；脱光装备让怪打死再跑尸也常用，但东瘟疫部分点位离墓地很远，慎用。

## 实现要点（1.12 客户端踩坑记录）

这套客户端有几个和教科书不一样的行为，本插件的写法都是按实测结果定下的：

| 现象 | 处理 |
| --- | --- |
| `WorldMapFrame:IsVisible()` 返回 `nil` | 完全不做可见性判断；钉子挂在 `WorldMapButton` 下，地图关闭时自然隐藏 |
| `GetMapInfo()` 会滞后一个区域（换图后仍返回上一张图的名字） | 区域识别改用**序号比对**：启动时从 `GetMapZones(大陆)` 扫出西/东瘟疫之地的序号，之后只比较 `GetCurrentMapZone()` 的数字 |
| `GetMapZones()` 有的实现返回表、有的返回多个值 | 两种都兼容 |
| `SetTexture("Interface\\Icons\\...")` 渲染为全黑 | 自带 TGA 贴图；且**必须写全 `.tga` 扩展名**，否则客户端只补 `.blp` |
| 换区时 `WORLD_MAP_UPDATE` 连发、地图框尺寸未定型 | 事件触发 + 0.3 秒防抖补帧，另挂 `WorldMapFrame_Update` 与 0.25 秒轮询兜底 |
